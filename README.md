## Project Description
A one-page portfolio with About, Skills, Projects and Contact sections. It works on phones, tablets and desktops.
 
## Features
- Time-based greeting and typing animation in the hero section
- Dark / light mode, saved in the browser with `localStorage`
- Sections that fade in while scrolling, with animated skill bars and counting stats
- Project filter buttons (All / Web / Python)
- Contact form with validation and friendly messages
- Back-to-top button
- Responsive navigation bar with a mobile menu (added in `feature-navbar`)
- Footer (added in `feature-footer`)

## How to Run
1. Clone the repository:
```bash
git clone https://github.com/your-username/GitHub-practical-test.git
```
2. Open the folder and double-click `index.html` (or open it in any browser).
No installation or build step is needed.
 
## Git Workflow
1. Created the repository and built the base portfolio on `main` with several commits.
2. Created `feature-navbar`, added the navigation bar, committed and pushed.
3. Created `feature-footer`, added the footer, committed and pushed.
4. Merged both branches into `main`, so the final `main` branch contains the navbar and the footer.
